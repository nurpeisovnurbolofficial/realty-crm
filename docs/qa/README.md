## Область проверки

Вход и выход, CSRF, роли и доступ к данным, формы клиентов и границы полей,
каталог объектов, этапы сделок, комиссии, причины проигрыша, заметки, задачи,
поиск, пагинация и доступ к рейтингу команды. В UI дополнительно проверены
выбранные подписи RU/EN, Escape и возврат фокуса, мобильная и настольная
карточка сделки.

Среда: отдельная локальная SQLite, синтетические учётные записи, `DEMO_MODE=False`.
Публичный demo и рабочие данные не изменялись. PostgreSQL-конкуренция, Firefox,
Safari iOS, сбой сети и ротация токенов отмечены **Not run**.
Последовательная проверка конфликта сделок не подтверждает работу row locks в PostgreSQL.

Материалы подготовлены с AI-ассистентом. Способ прогона, границы и исходные
доказательства сохранены, чтобы проверки можно было изучить и повторить.
