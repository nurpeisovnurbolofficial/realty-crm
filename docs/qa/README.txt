КАК ПОВТОРИТЬ ДВА ДЕФЕКТА API В ОТДЕЛЬНОЙ ЛОКАЛЬНОЙ БАЗЕ
1. Используйте Realty CRM на указанной ревизии с установленными backend-зависимостями
   и собранной frontend/dist. Обычную базу проекта эти скрипты не используют.
2. Откройте PowerShell в папке reproduce из распакованного архива.
3. Укажите путь к backend и Python этого проекта:
   $env:REALTY_CRM_BACKEND = 'C:\path\to\realty-crm\backend'
   $qaPython = Join-Path $env:REALTY_CRM_BACKEND '.venv\Scripts\python.exe'
4. Создайте отдельную базу рядом со скриптами:
   & $qaPython -B .\setup_environment.py
5. Запустите локальный сервер:
   & $qaPython -B .\serve.py
6. Во втором PowerShell в этой же папке повторите команды шага 3, затем запустите:
   & $qaPython -B .\reproduce_defects.py
   Успешное повторение выводит BUG-001 reproduced: True и BUG-002 reproduced: True.
   Если баг исправлен, ожидается False; проверьте новый ответ в recheck-results.json.
7. Для проверки через браузер откройте http://127.0.0.1:8765.
   Пользователи: qa_manager_a, qa_manager_b, qa_head.
   Пароль только этих синтетических локальных пользователей: QaPortfolioOnly2026!
   BUG-003 воспроизводится вручную по шагам в соответствующем TXT/PDF-отчёте.
8. Остановите тестовый сервер Ctrl+C после проверки.
